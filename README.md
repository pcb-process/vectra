# Smart Personal Finance (Next.js + Supabase)

เว็บแอปพลิเคชันจัดการการเงินส่วนบุคคลอัจฉริยะ รองรับทั้งการใช้งานบนคอมพิวเตอร์และมือถือ (Responsive Design) พัฒนาด้วย **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, **Recharts** และฐานข้อมูล **Supabase Postgres (Free Tier)**

## ฟีเจอร์หลัก (Core Features)
1. **Dashboard & Analytics**:
   - แสดงการ์ดสรุปรายรับรวม, รายจ่ายรวม, เงินคงเหลือสุทธิ (Net Cashflow) และอัตราการออม (Savings Rate %)
   - กราฟเปรียบเทียบแนวโน้มรายรับ-รายจ่ายรายวันภายในเดือน (`BarChart`)
   - กราฟวงกลมแสดงสัดส่วนค่าใช้จ่ายแยกตามหมวดหมู่ (`PieChart`) พร้อมจัดอันดับหมวดหมู่ที่ใช้จ่ายสูงสุด
2. **Income & Expense Tracking (บันทึกรายรับ-รายจ่าย)**:
   - เพิ่ม แก้ไข และลบรายการธุรกรรมแยกตามหมวดหมู่ สี และไอคอน
   - ค้นหาจากบันทึกช่วยจำ กรองตามประเภทรายการ (รายรับ/รายจ่าย) และกรองตามหมวดหมู่
3. **Budgeting & Smart Alerts (ตั้งงบประมาณและแจ้งเตือนอัจฉริยะ)**:
   - กำหนดวงเงินงบประมาณรายเดือนแยกตามหมวดหมู่ พร้อมกำหนดเกณฑ์แจ้งเตือน (`alert_threshold` เช่น 80%)
   - แจ้งเตือนด้วยแถบสถานะอัตโนมัติ: ปกติ (สีเขียว), ใกล้เต็มงบ (สีเหลืองส้ม), และเกินงบ (สีแดง)
4. **Supabase Cloud Sync & Demo Mode**:
   - รองรับการเข้าสู่ระบบ/สมัครสมาชิกผ่าน **Supabase Auth** พร้อม **Row Level Security (RLS)** แยกข้อมูลของผู้ใช้แต่ละคนอย่างปลอดภัย
   - มี **Demo Mode** พร้อมข้อมูลตัวอย่างให้ทดลองใช้งานได้ทันทีโดยไม่ต้องล็อกอิน

## การรันโปรเจกต์ในเครื่อง (Local Development)

```bash
npm install
npm run dev
```

เปิดเบราว์เซอร์ที่ `http://localhost:3000`
